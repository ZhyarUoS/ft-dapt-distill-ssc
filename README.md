# A Comparative Analysis of Semi-Supervised Fine-Tuning Strategies for Sequential Sentence Classification in Biomedical Abstracts

> **Status:** 📝 Submitted for review. DOI and citation details will be added upon acceptance.

## Overview

This project compares three fine-tuning approaches for sequential sentence classification (SSC) in biomedical abstracts — direct fine-tuning, fine-tuning with domain-adaptive pretraining (DAPT), and fine-tuning with soft knowledge distillation — all built on a shared contrastive pretraining and local-context concatenation foundation. All approaches are evaluated with bootstrap confidence intervals and paired significance testing across three biomedical PLMs (PubMedBERT, BioLinkBERT, BioBERT) on the PubMed 20k RCT benchmark.
